Host scan results

Accounts that run the SQL Server services, reviewed in Active Directory (read-only). Virtual and built-in accounts (NT Service, LocalSystem, Network Service) use the host's computer account on the network, so that account is reviewed for them. Local admin is checked on the hosts whose local Administrators group could be read.

Hosts that could not be fully verified. "Inconclusive" means the host answered but neither the registry nor the Windows services could be read, so SQL Server may still be installed there.
